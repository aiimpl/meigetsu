# 今夜の名月

2026年の中秋の名月（9月25日）は、満月ではありません。満月は2日後の9月27日 1時49分。
このページは「今夜の本物の月」を天文計算どおりに描き、そのずれを触って確かめる体験型のシミュレーターです。

**ブラウザで開く：https://aiimpl.github.io/meigetsu/**

## できること
- 縁側から見た今夜の月。位置・欠け方・模様の傾き・秤動（見える面のわずかな揺れ）を、選んだ場所と時刻から計算
- 望遠鏡の月を横にドラッグすると時間が進み、「満月まで、あと1.8%」が0%になるまで追える
- 「月の出を望遠で」：600mmのレンズで、山の端から赤く昇る月を再現（低い月が赤く暗くなる大気減光も計算）
- 「この月を撮る」：日付・場所・輝きの割合が入った名月写真を保存
- 札幌〜那覇の8都市と現在地、14mm〜600mmのレンズ、薄雲、秋の虫の声（コードで合成）

## 使っている事実（すべて計算で確認）
| 項目 | 値 |
|---|---|
| 新月（旧暦8月1日） | 2026年9月11日 12:27 |
| 十五夜 | 2026年9月25日 |
| 満月 | 2026年9月27日 1:49 |
| 新月→満月 | 15.56日（2000〜2050年の範囲は13.91〜15.61日） |
| 遠地点 | 9月19日 404,210 km |
| 十五夜と満月が2日ずれる年（2000〜2050年） | 2000, 2007, 2016, 2017, 2026, 2043, 2044 |
| 次に十五夜と満月が同じ日になる年 | 2030 |

中秋の名月の日付は「秋分を含む旧暦月（8月）の15日目」として求めています。

## 仕組み
- HTML 1ファイル。画像・3Dモデル・音声ファイルは使わず、地形・ススキ・松・月面・雲・音はすべてコードで生成
- 月面の明るさはロンメル・ゼーリガー則（満月が縁まで平らに明るく見える反射）
- 外部サービスへの接続はありません（ライブラリとフォントは同梱）

手元で動かす場合は、ESモジュールを読み込むためローカルサーバー経由で開いてください（例：`python3 -m http.server` → http://localhost:8000）。
